# Bundled fonts

- `bootstrap-icons.woff`: Bootstrap Icons 1.13.1 (MIT). Glyph codepoints from its `bootstrap-icons.css`. See `LICENSE-bootstrap-icons.txt`.
- `NotoSans-Regular.woff`, `NotoSans-SemiBold.woff`: Noto Sans latin subset (SIL Open Font License 1.1), via `@fontsource/noto-sans` 5.3.0. See `LICENSE-noto-sans.txt`.

The fonts are embedded with `include_bytes!` so the UI looks the same on every platform.
